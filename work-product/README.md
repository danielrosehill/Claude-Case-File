# Work Product Directory

This directory contains attorney work product - materials prepared in anticipation of litigation.

## ⚠️ PRIVILEGED MATERIALS

Contents of this directory may be protected by attorney work product doctrine. Do not disclose without counsel approval.

## Structure

```
work-product/
├── drafts/           # Document drafts
├── bundles/          # Prepared document bundles
├── exports/          # Exported case materials
├── summaries/        # Case summaries
└── privilege-review/ # Privilege review materials
```

## Subdirectories

### drafts/
Working drafts of letters, motions, and other documents. Not final versions.
Naming: `[date]-[type]-[description]-DRAFT.[ext]`

### bundles/
Compiled document bundles for specific purposes (counsel briefing, discovery, etc.)
Naming: `[date]-[purpose]/`

### exports/
Complete case exports for archiving or sharing.
Naming: `[date]-[type]-export/`

### summaries/
Generated case summaries and status reports.
Naming: `[date]-[type]-summary.md`

### privilege-review/
Privilege analysis and logs.
- `privilege-log.md` - Running log of privileged documents
- Individual review files

## Best Practices

1. **Label clearly**: Mark all drafts as "DRAFT"
2. **Date everything**: Use YYYY-MM-DD format
3. **Maintain versions**: Use git for version history
4. **Segregate privilege**: Keep privileged materials separate
5. **Review before sharing**: Verify privilege status before any disclosure
