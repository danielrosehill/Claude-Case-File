# Context Directory

This folder contains background materials, reference documentation, and contextual information that Claude should reference when working on this case.

## Contents

Place the following types of materials here:

### Case Background
- `case-background.md` - Overview of the dispute, history, and key facts
- `legal-framework.md` - Applicable laws, regulations, and precedents

### Party Information
- `party-profiles.md` - Detailed information about all parties
- `relationship-history.md` - History of relationships between parties

### Subject Matter
- Domain-specific reference materials relevant to the case
- Industry standards or regulations at issue
- Technical documentation if relevant

### Procedural Context
- `procedural-history.md` - History of court proceedings
- `pending-deadlines.md` - Outstanding deadlines and requirements

## Usage

Claude will read files in this directory to gain context about the case. Keep materials here current and well-organized.

**Note**: Do not place evidence files here. Evidence belongs in `/evidence/` with proper checksums.
