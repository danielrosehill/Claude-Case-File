# Document Templates

This directory contains templates for common legal documents. These are starting points only - all documents should be reviewed and customized by qualified legal counsel.

## Available Templates

### Correspondence
- `demand-letter.md` - Demand letter template
- `settlement-letter.md` - Settlement proposal template

### Discovery
- `interrogatories.md` - Interrogatory template
- `rfp.md` - Request for Production template
- `rfa.md` - Request for Admission template

### Court Filings
- `motion-template.md` - Basic motion framework
- `declaration-template.md` - Declaration template

### Internal
- `memo-template.md` - Legal memorandum template
- `case-summary-template.md` - Case summary template

## Usage

1. Copy the relevant template
2. Customize for your jurisdiction and case
3. Have counsel review before filing or sending
4. Save final versions to appropriate `documents/` subdirectory

## Disclaimer

These templates are provided for organizational purposes only and do not constitute legal advice. All documents should be reviewed by qualified legal counsel before use.
