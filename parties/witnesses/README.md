# Witnesses Directory

This folder contains information about witnesses in the case.

## Witness File Format

Create individual files for each witness: `[name]-witness.md`

```markdown
# Witness: [Full Name]

## Contact Information
- Name:
- Address:
- Phone:
- Email:
- Employer:

## Relationship to Case
- Connection to parties:
- Role in events:
- Favorable/Adverse:

## Testimony Summary
- Key facts they can attest to:
- Areas of knowledge:

## Statements/Depositions
- [Date]: [Type of statement] - See [document reference]

## Credibility Notes
- Strengths:
- Potential weaknesses:
- Bias concerns:

## Contact History
| Date | Contact Type | Notes |
|------|--------------|-------|
| | | |
```

## Witness Categories

Organize witnesses by type:
- **Fact Witnesses**: Direct knowledge of events
- **Character Witnesses**: Testimony about character
- **Expert Witnesses**: See `experts/` directory

## Notes

- Keep witness contact information current
- Document all communications with witnesses
- Note any privilege or work product concerns
