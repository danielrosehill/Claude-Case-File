# Counsel Directory

This folder contains information about legal counsel involved in the case.

## Your Counsel

Create a file `your-counsel.md` with:

```markdown
# Your Legal Counsel

## Lead Attorney
- Name:
- Firm:
- Email:
- Phone:
- Bar Number:

## Additional Team Members
- [Name] - [Role]

## Communication Preferences
- Preferred contact method:
- Response time expectations:
```

## Opposing Counsel

Create a file `opposing-counsel.md` with:

```markdown
# Opposing Counsel

## Lead Attorney
- Name:
- Firm:
- Address:
- Email:
- Phone:

## Additional Team Members
- [Name] - [Role]

## Notes
- [Any relevant notes about opposing counsel]
```

## Usage

When corresponding with counsel, reference these files for accurate contact information.
